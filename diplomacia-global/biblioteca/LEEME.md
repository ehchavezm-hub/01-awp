# Mi biblioteca personal

Copie aquí sus libros en formato **.md** o **.txt** (por ejemplo, `Diplomacia_Kissinger_Henry.md`).

Cuando busque un tema con el servidor encendido (`npm start`), Diplomacia Global
mostrará los **párrafos de sus libros** donde aparece ese tema, con el capítulo y la
ubicación aproximada.

- Sus libros **no se suben a internet** ni a GitHub: esta carpeta está excluida en `.gitignore`.
- El archivo `libros.json` (opcional) indica el título, autor y año de cada libro.
  La clave es una parte del nombre del archivo.
